# PICA PICA 近景性能修复 · 2026-10-27

近景移动时，旧版的历史累计权重会按实际帧时间缩短，却又被用来判断“是否至少积累了四帧”。
帧率低于阈值后，稳定表面长期被分配 64 条漫反射射线，进一步压低帧率。
本版分别记录几何验证通过的观察次数与时间滤波权重，保留原有响应时间、新显露区域补采样和反射历史验证。

## 性能

RTX 5070 Ti 16 GB，1920×1080，PICA 视角 1；近景为 `--camera-dolly 42`。
全分辨率反射，基础 4 样本，自适应上限和降噪设置保持不变。
每组预热 200 帧、测量 120 帧；顺序独占测试，测前未发现 Albor 或其他测试渲染器。
下表是实际墙钟帧率；20/60 Hz 指相同的模拟步长，不是帧率上限。
20 Hz 用于重现低帧率时的历史预算问题，优化前后逐帧使用相同的相机与光源状态。
优化前为 `d29a5b6` 的渲染算法，仅补入相机前移和诊断时钟参数；每组二进制指纹均保存在捕获凭据中。

| 条件 | 优化前 FPS | 优化后 FPS | 帧时间 P95，ms |
| --- | ---: | ---: | ---: |
| 外侧静止，60 Hz | 56.5 | 61.0 | 18.2 → 16.9 |
| 近景静止，60 Hz | 28.0 | 30.7 | 36.1 → 32.9 |
| 近景相机运动，20 Hz | 9.0 | 20.9 | 126.3 → 62.6 |
| 近景相机＋光源运动，20 Hz | 8.9 | 20.3 | 126.1 → 62.8 |

另测实际帧时间驱动历史滤波的近景回放：相机运动 23.9 FPS，
相机＋光源运动 23.2 FPS。
此模式固定每帧重放的相机姿态，避免用“帧序号 × 变化的 dt”制造相机跳变；普通鼠标键盘控制不受影响。
性能仍受近景覆盖率、运动速度及新显露表面数量影响，当前没有达到所有近景下稳定 60 FPS。

## 保留的优化

- 漫反射和高光的有效观察次数独立累计到四次，不再受时间滤波权重的上限影响。
- PICA 的漫反射次级命中复用已有 6×6 法线方向余弦积分图，避免每条射线重复遍历 32 个方向。
  每帧在探针分配后、追踪前从同一份 base_radiance 重建，防止回收槽位或清空缓存后读到旧图块。
  此项具有方向插值近似；`--exact-diffuse-feedback` 保留精确积分对照。
- 漫反射工作队列按活动 warp 合并分配，保持每条射线、像素归一化和首条次级路径；
  PICA 主追踪 kernel 使用 64 个寄存器上限，其他场景保持原设置。
