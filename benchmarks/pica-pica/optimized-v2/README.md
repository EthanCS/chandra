# PICA PICA 间接高光收尾 · 2026-10-27

保留数值 GGX／RC／RT 方案，LTC 实验实现、查表资源、开关和导出工具已移除。
本版包含正确的 PICA 材质、镜面与光滑反射光追、粗糙远场 RC、可见性判断、
自适应补采样及空间／时间重建。默认基础预算为 4，反射全分辨率输出。

这不表示桌面进程绝对没有 GPU 活动。原始 CSV、参数和 GPU 遥测在 [profile](profile/static/receipt.json)。

## 本次保留的执行优化

- 相机移动不再把普通漫反射像素的基础预算全屏放大到 8／16；
  保留局部历史失效补采样，并修正四帧历史的浮点舍入判断。
- 反射命中共用材质读取和直接着色；只在太阳光阴影起点完全相同时复用可见性。
  漫反射与高光的点光阴影端点仍各自保留。
- 1080p 及以下的高预算反射拆成单射线任务，细化 kernel 限制为 96 个寄存器；
  读取实际队列长度后仅调度必要工作，避免空队列占用整屏任务。
  超过 1080p 默认批次为 32，以限制暂存内存；4K 尚未验证。
- 保留 16／32／64／128 的局部样本预算、相同 Sobol 前缀以及新显露金属的高预算。
  测试对比串行与 1／2／4／8／16／32 批次，并覆盖实际队列长度的调度路径。
- 短任务暂存区在 1080p 约 3.21 GiB，比前一版本更大；本轮整卡显存约 7 GiB。
  可用 `--specular-serial`、`--specular-batch N`、`--specular-registers N` 做开发对照。

## 验证和使用

`./run-lighting-lab.ps1 -Test`：39 项 Rust／GPU 测试通过。
材质映射、反射重投影和漫反射验证工具的 Python 检查通过。
测试命令、源码指纹和二进制指纹见 [validation.json](validation.json)。

```powershell
./tools/setup-pica-pica.ps1
./run-lighting-lab.ps1 -PicaPica -FullHD -Static -View 1
```

面板提供 `Indirect reflections` 和 `Reflections only`。
PICA 的 145 个源对象／170 个材质网格、76300 个三角形、28 个材质和 6 张贴图
由导入工具配置。资产保存在忽略的 external 目录，上传的是导入工具、材质元数据及署名说明。
玻璃仍为不透明反射近似，未实现折射；原作 HDR 灯光也未复现。
